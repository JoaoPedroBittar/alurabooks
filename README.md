# 📚 AluraBooks

**Projeto desenvolvido para estudo no curso "HTML e CSS: responsividade com mobile-first" da Alura.**

O objetivo é construir uma página responsiva de livraria online, utilizando boas práticas de HTML5 e CSS3.

## 🎯 Funcionalidades

*   **Layout Responsivo** seguindo o conceito mobile first
*   **Cabeçalho Dinâmico**
    *   Menu hambúrguer no mobile
    *   Navegação horizontal no desktop
*   **Banner** com Campo de Busca estilizado
*   **Carrossel de Livros** usando Swiper.js
*   **Cards de Destaques** com textos e imagens
*   **Sessão de Tópicos Recentes**
*   **Formulário de Contato** com input estilizado
*   **Rodapé Completo** com links e divisões organizadas

## 🛠️ Tecnologias Utilizadas

*   HTML5
*   CSS3
*   Mobile First
*   Flexbox
*   Media Queries
*   Swiper.js (carrossel)
*   Google Fonts: Poppins e Josefin Sans

## 🚀 Como Executar o Projeto

1.  Baixe ou clone o repositório:
    ```bash
    git clone https://github.com/JoaoPedroBittar/alurabooks.git
    ```
2.  Certifique-se de que a pasta `img/` contém todas as imagens do projeto.
3.  Abra o arquivo `index.html` diretamente no navegador.
